Endurance limit (Marin factors)

Se = ka · kb · kc · kd · ke · kMisc · Se′, steel, MPa and mm.

Material and surface
For combined bending and torsion through von Mises, choose bending.
Size
Environment

Equations 
Se' = 0.5 Sut  (Sut <= 1400 MPa),  Se' = 700 MPa otherwise
ka  = a Sut^b           (surface, Sut in MPa)
kb  = (de/7.62)^-0.107  for 2.79 <= de <= 51 mm;   1.51 de^-0.157 for 51 < de <= 254 mm
kc  = 1 bending, 0.85 axial, 0.59 torsion
kd  = temperature table (linear interpolation)
ke  = reliability table

Fluctuating stress: factors of safety

Goodman, Soderberg, Gerber and ASME-elliptic fatigue criteria plus Langer first-cycle yield. Stresses in MPa, both components non-negative.

Stresses and strengths
Equations 
Goodman    1/n = σa/Se + σm/Sut
Soderberg  1/n = σa/Se + σm/Sy
Gerber     n σa/Se + (n σm/Sut)^2 = 1
ASME       (n σa/Se)^2 + (n σm/Sy)^2 = 1
Langer     n = Sy / (σa + σm)

Shaft: static yield (distortion energy)

Solid round shaft, steady bending moment and torque. Moments in N·m (converted to N·mm internally).

Loads and material
Equations 
d = [ (16 n / (pi Sy)) sqrt(4 M^2 + 3 T^2) ]^(1/3)
sigma' = (16 / (pi d^3)) sqrt(4 M^2 + 3 T^2),   n = Sy / sigma'

Shaft: fatigue (DE criteria)

Diameter for a target design factor with DE-Goodman, DE-Soderberg, DE-Gerber and DE-ASME-elliptic, and factors of safety for a given diameter. Moments in N·m.

Load components
Material and design factor
Equations 
A = sqrt(4 (Kf Ma)^2 + 3 (Kfs Ta)^2)      B = sqrt(4 (Kf Mm)^2 + 3 (Kfs Tm)^2)
Goodman    d = [ (16 n / pi) (A/Se + B/Sut) ]^(1/3)
Soderberg  d = [ (16 n / pi) (A/Se + B/Sy) ]^(1/3)
Gerber     d = [ (16 n / pi) * 0.5 (A/Se + sqrt((A/Se)^2 + 4 (B/Sut)^2)) ]^(1/3)
ASME       d = [ (16 n / pi) sqrt((A/Se)^2 + (B/Sy)^2) ]^(1/3)
sigma_a' = 16 A / (pi d^3),   sigma_m' = 16 B / (pi d^3)
first-cycle yield: sigma_max' = (16/(pi d^3)) sqrt(4 (Kf (Ma+Mm))^2 + 3 (Kfs (Ta+Tm))^2)

Eccentrically loaded bolt group (shear)

Centroid, primary and secondary shear, resultant per bolt and the critical bolt. x to the right, y up, moments counter-clockwise positive. mm and N.

Geometry and load
Leave out the area when all bolts are identical.
Stresses (optional)
Equations 
M = (xF - xbar) Fy - (yF - ybar) Fx + couple          (about the centroid)
F'_i  = F A_i / sum(A)                                 (primary, direct)
F''_i = M A_i r_i / sum(A_j r_j^2), perpendicular to r_i   (secondary)
R_i   = F'_i + F''_i  (vector sum);  tau = R / (pi d^2 / 4);  sigma_b = R / (d t)
